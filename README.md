The program writes exactly that line (110 characters, one line, UTF-8, no trailing newline) to `/output/entry.txt`. Deterministic: constant string plus a length/single-line gate and a byte-identical round-trip check — no wall-clock, no randomness.

Run it with Node 22:

```sh

```
